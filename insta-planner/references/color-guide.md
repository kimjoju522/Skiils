# 포인트 색상·폰트 가이드

기본 가이드다. 아래 조합은 출발점이고, 주제에 맞는 색이 따로 있으면 그걸 우선한다.

## 색상을 정하는 순서

1. **주제 속 색을 먼저 찾는다.** 제품 색, 계절, 퍼스널컬러, 올해의 트렌드 컬러, 장소의 분위기.
2. **메인 → 서브 → 포인트 → 글자색** 순서로 정한다.
3. **비율은 70 : 20 : 10**. 메인(배경) 70, 서브 20, 포인트 10.
4. **포인트는 한 가지만.** 제목 강조, 숫자, 밑줄, 버튼 정도에만 쓴다.
5. **대비를 확인한다.** 배경과 글자의 밝기 차이가 커야 한다. 본문은 배경이 밝으면 거의 검정에 가까운 짙은 색, 어두우면 흰색 계열로 둔다. 연한 글자색을 연한 배경 위에 쓰지 않는다.
6. **계정 안에서는 반복한다.** 시리즈나 계정 전체에서 메인 또는 포인트 하나는 같게 두면 피드가 통일돼 보인다.

## 포인트 색 고르는 법

| 메인(배경) 느낌 | 포인트 방향 | 효과 |
|---|---|---|
| 밝고 부드러운 배경 | 채도 높은 색 1개 | 시선이 모임, 생기 |
| 어두운 배경 | 밝고 선명한 색 | 고급스럽고 또렷함 |
| 무채색 배경 | 어떤 색이든 가능 | 포인트가 주인공이 됨 |
| 이미 색이 많은 사진 위 | 흰색 또는 검정 | 사진을 해치지 않음 |

## 계절·시기별 방향

- **봄**: 파스텔 핑크·연두·연노랑
- **여름**: 선명한 코랄·민트·블루
- **가을**: 베이지·브라운·버건디 톤
- **겨울/연말**: 차가운 블루, 딥 와인, 다크+골드
- 올해의 트렌드 컬러(예: 팬톤 선정색)는 **최신 정보를 검색해서** 확인한 뒤 반영한다. 기억에 의존하지 않는다.

## 퍼스널컬러 관련 주제일 때
- 웜톤 주제: 베이지·코랄·브라운 계열 배경이 자연스럽다.
- 쿨톤 주제: 블루·라벤더·뮤트 로즈 계열 배경이 자연스럽다.
- 같은 게시물 안에서 웜과 쿨을 비교할 때는 카드마다 배경을 해당 톤으로 바꾸면 한눈에 구분된다.

## 폰트 느낌 가이드

한 게시물에서 **폰트는 2종 이하**. 제목용 하나, 본문용 하나.

| 분위기 | 제목 폰트 느낌 | 본문 폰트 느낌 |
|---|---|---|
| 깔끔·정보 | 굵은 고딕 | 보통 굵기 고딕 |
| 감성·에세이 | 얇은 명조 또는 손글씨체 | 부드러운 고딕 |
| 귀엽·캐주얼 | 둥근 고딕, 손글씨체 | 둥근 고딕 |
| 트렌디·에디토리얼 | 굵은 세리프 계열 하나 (영문과 한글 같은 폰트) | 가는 고딕 |

사용 가능한 폰트는 도구에 따라 다르다. Canva나 Google Fonts에서 무료로 쓸 수 있는 폰트를 우선 추천하고, 상업 이용 라이선스를 확인하도록 한 줄 안내한다.

## 레이아웃 기본 규칙

- 비율 **4:5 (1080×1350)** 또는 Canva 기본인 **3:4 (1080×1440)**. 도구의 기본을 따르고, 4:5가 꼭 필요할 때만 변환한다.
- Canva로 만든 뒤에는 **지정한 HEX, 폰트 2종 이하, 여백 80px**이 실제로 지켜졌는지 확인한다.
- 가장자리에서 **최소 80px** 안쪽에 텍스트를 둔다 (프로필 격자 미리보기에서 잘려도 안전)
- 제목 크기 > 본문 크기를 뚜렷하게 (최소 1.8배)
- 본문 글자는 모바일에서 읽히도록 **너무 작게 쓰지 않는다** (1080 기준 40px 이상)
- 장마다 제목 위치와 번호 위치를 **고정**한다
- 사진이 있으면 글자 뒤에 반투명 면을 깔아 가독성을 확보한다

## 제안할 때의 출력 형식

```
A안 뮤트 로즈
- 메인 #F4EDE8 / 서브 #D9B9B4 / 포인트 #B5485D / 글자 #2B2326
- 폰트: 제목 굵은 고딕, 본문 부드러운 고딕
- 이유: 쿨뮤트 립 주제의 색감과 맞고, 차분하면서 포인트가 또렷함
```

2~3안을 제안하고, 안마다 분위기가 확실히 다르게 한다.

HEX만 적지 말고 **실제 색 견본**을 함께 보여 준다. 방법은 SKILL.md 5단계와 `assets/color-swatch.html`(색 견본 + 견본 카드 + 대비 수치)을 따른다.
