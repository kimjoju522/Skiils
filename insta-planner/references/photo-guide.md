# 제품 사진 가이드

제품 큐레이션이나 후기형 게시물에서 사진을 구하고 넣는 방법이다. 기본 가이드이고, 상황에 맞게 바꿔도 된다.

## 사진을 구하는 순서

1. **사용자가 직접 찍은 사진** (가장 안전하고 계정 분위기도 살린다)
2. **브랜드가 보도자료·소개용으로 허용한 이미지** (허용 문구를 원문에서 확인한 것)
3. **공식몰·판매처의 상품 이미지** (사용 허락이 필요할 수 있다고 알리고 출처를 적는다)
4. 위가 모두 안 되면 **컬러 칩(근사색)과 글자**로 만든다

쓰지 않는 것: 후기 사이트의 이용자 사진, 인플루언서 사진, 다른 계정의 게시물 이미지, 제품이 아닌 AI 생성 이미지를 제품 사진처럼 쓰는 것.

## 판매 페이지 이미지가 컬러와 맞는지 확인하는 법

컬러 선택형 상품("23종 택1")은 대표 이미지가 전 컬러 모음이거나 다른 컬러일 수 있다.
- 상품 옵션(컬러 선택)을 눌러 **그 컬러의 이미지나 스와치 이미지**가 따로 있는지 브라우저로 확인한다.
- 이미지에서 컬러명·번호가 보이거나, 컬러가 컬러명 설명과 일치할 때만 쓴다.
- 확인이 안 되면 그 제품은 컬러 칩으로 바꾸고, 사용자에게 직접 찍은 사진을 부탁한다.

## 사용자에게 사진을 부탁할 때 쓸 안내문

다음 내용을 짧게 전한다.
- 넣을 자리: 제품 카드마다 1장(제품 사진). 표지(제품 모음 사진)와 비교 카드(나란히 놓은 사진)는 Canva에서만 넣을 수 있다. HTML 카드는 제품 카드에만 사진 자리가 있다.
- 방향과 크기: **세로 사진**이 카드에 잘 맞는다. 제품을 가운데 두고 위아래 여백을 남긴다.
- 배경: 단색(흰색, 베이지)이나 자연광 창가가 깔끔하다. 카드 배경과 너무 비슷한 색은 피한다.
- 컬러 확인: **색 번호가 보이게** 라벨이나 립 끝(팁)을 같이 찍는다.
- 색이 중요한 제품(틴트, 블러셔)은 **자연광**에서 찍고 보정을 많이 하지 않는다.
- 사진 파일은 경로로 알려 주거나 `images/` 폴더에 넣어 달라고 한다. (안내만 하고 멈추지 않는다. 사진이 오면 그때 넣는다.)

## 사진 파일을 게시물에 넣는 법

### HTML 카드
**가장 쉬운 방법**: 제품 카드의 **사진 자리**(컬러 칩과 "사진 넣기" 안내)를 클릭해서 사진을 고르거나, 사진 파일을 그 자리에 끌어다 놓는다. 사진은 컴퓨터 안에서만 처리되고, 저장하는 PNG에 들어간다. 안내 글자와 "근사색" 표시는 사진이 들어가면 사라지고 PNG에도 나오지 않는다.

**폴더에 넣는 방법** (스킬이 대신 넣을 때):
1. 사진을 작업 폴더의 `images/`에 복사한다(파일 이름은 `01.jpg`처럼 짧게).
2. `CARDS`의 `product` 카드에 `img:'images/01.jpg'`로 넣는다. 파일이 없거나 못 불러오면 **컬러 칩으로 자동 대체**된다.
3. 이미지 주소(`https://...`)를 직접 넣으면 PNG 저장 때 빠질 수 있으니 항상 내려받아 쓴다.

### Canva
1. `create-upload-url`로 1회용 주소를 받는다.
2. 파일 내용을 그대로 보낸다: `curl -X POST -H "Content-Type: application/octet-stream" --data-binary @파일경로 "받은주소"` → `{"mediaId":"..."}`가 돌아온다.
3. `read-design`으로 트랜잭션을 열고 `edit-design`의 `insert_fill`(`page_id`, `asset_type: image`, `asset_id: mediaId`, `alt_text`, `left`·`top`·`width`·`height`)로 넣는다. 위치는 **글자와 겹치지 않는 빈 영역**에 둔다. 새로 만들 때는 `create-design`의 `references`에 `mediaId`를 넣어도 된다.
4. 공개 이미지 주소는 `upload-asset-from-url`이 더 간단하지만, 일부 사이트는 가져오기를 거부(`fetch_failed`)한다. 그때는 위 방법을 쓴다.

## 로고
로고는 브랜드 상표다. 사용자가 요청했을 때만 넣고, 브랜드 공식 페이지의 로고 주소를 출처와 함께 확인받는다. 확인이 안 되면 글자로 브랜드 이름만 쓴다.
