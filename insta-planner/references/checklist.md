# 업로드 전 체크리스트

게시물을 다 만든 뒤 점검하고, 걸리는 항목만 짧게 알린다.

## 1. 내용
- [ ] 표지가 약속한 내용을 본문이 지켰는가
- [ ] 장마다 메시지가 하나인가
- [ ] 마지막 장에 행동 유도(저장·질문)가 있는가
- [ ] 사실·수치·가격·날짜를 확인했는가 (확인 못 한 건 "확인 필요"로 남기기)
- [ ] 직접 경험하지 않은 후기를 경험처럼 쓰지 않았는가

## 2. 표기와 규정
- [ ] 협찬·광고·제공받은 제품이면 광고 표기를 했는가 (캡션 앞부분과 이미지 안에서 눈에 띄게)
- [ ] 효능·효과를 단정하는 표현이 없는가 (화장품, 건강, 식품은 특히)
- [ ] 활동 단체(서포터즈·기자단 등)의 **게시 가이드라인**을 확인했는가: 필수 해시태그, 계정 태그, 금지 표현, 게시 기한

## 3. 저작권·초상권
- [ ] 이미지: 직접 찍었거나 사용 허용된 것만 썼는가
- [ ] 폰트: 상업 이용 가능 여부를 확인했는가
- [ ] 음악(릴스): 인스타그램 라이브러리에서 고른 것인가
- [ ] 다른 사람 얼굴이 나왔다면 동의를 받았는가
- [ ] 다른 계정의 게시물을 인용했다면 출처를 적었는가

## 3-1. 음식·식품 주제라면
- [ ] 알레르기를 일으킬 수 있는 재료(견과, 갑각류, 유제품 등)를 표시했는가
- [ ] 보관 방법과 기한, 익힘 정도 등 **조리·보관 안전** 정보가 정확한가 (확인 못 한 건 "확인 필요")
- [ ] 가격은 직접 산 금액과 구입처·시점만 썼는가 (다른 곳의 가격을 가져오지 않았는가)
- [ ] 협찬·제공받은 식재료·도구면 광고 표기를 했는가
- [ ] 건강·다이어트 효과를 단정하지 않았는가

## 3-2. 제품·브랜드를 소개하는 주제라면
- [ ] 제품명·컬러명·용량은 **원문(공식 또는 판매 페이지)에서 확인한 것**인가
- [ ] 가격에 **확인한 날짜**를 적었는가 (가격은 바뀔 수 있음), 품절·단종 여부를 확인했는가
- [ ] 공식 설명은 "공식 설명에 따르면"으로, 써 보지 않은 제품의 발색·지속력을 경험처럼 쓰지 않았는가
- [ ] **제품 이미지**: 사용자가 직접 찍었거나, 브랜드가 사용을 허용한 것인가 (허락이 불확실하면 쓰지 않고 컬러 칩으로 대체)
- [ ] 이미지 출처(브랜드·페이지)를 캡션이나 카드에 적었는가
- [ ] 컬러 칩에 "근사색(실제와 다를 수 있음)"을 표시했는가
- [ ] "1위", "최고", "무조건" 같은 우열·순위 단정이 없는가
- [ ] 협찬·제공 제품이면 광고 표기를 했고, 직접 산 게 아니면 "내돈내산"이라고 쓰지 않았는가

## 4. 디자인
- [ ] 글자가 배경에서 또렷하게 읽히는가 (폰으로 봤을 때)
- [ ] 가장자리에서 80px 이상 안쪽에 글자가 있는가
- [ ] 폰트가 2종 이하인가
- [ ] 카드마다 제목·번호 위치가 일정한가
- [ ] 오탈자, 띄어쓰기를 확인했는가
- [ ] 첫 장이 프로필 격자에 작게 보여도 알아볼 수 있는가
- [ ] (Canva) 지정한 글자색·포인트색 HEX와 폰트가 그대로 적용됐는가

## 5. 게시 시간
- 정답이 있는 건 아니다. 일반적으로 **퇴근·점심·잠들기 전** 시간대가 반응이 좋다고 알려져 있지만 계정마다 다르다.
- 초반에는 **같은 요일·시간에 올려 보고**, 인스타그램 인사이트에서 팔로워가 활동하는 시간을 확인해서 조정하도록 제안한다.
- 처음 시작하는 계정은 시간을 맞추는 것보다 **주 2~3회 꾸준히** 올리는 것이 더 중요하다고 알려 준다.
