# 후킹·캡션·해시태그 가이드

기본 가이드다. 말투는 항상 `profile.md`를 우선한다.

## 표지 후킹 공식

표지는 정보를 주는 곳이 아니라 **궁금하게 만드는 곳**이다. 20자 안팎.

| 공식 | 예시 (주제만 바꿔 쓴다) |
|---|---|
| 숫자 + 결과 | "3분 만에 끝나는 OO" |
| 대상 지정 | "OO한 사람만 보세요" |
| 실수 지적 | "OO할 때 다들 이거 틀려요" |
| 결론 먼저 | "결론부터, OO은 이게 답" |
| 비교 구도 | "A vs B, 진짜 승자는?" |
| 감탄·공감 | "이거 보고 분위기 미쳤다 싶었음" |
| 비밀·꿀팁 | "아는 사람만 아는 OO" |

- 과장·낚시는 피한다. 표지가 약속한 건 본문에서 반드시 지킨다.
- 숫자는 구체적일수록 좋다. 단, 사실이 아닌 수치는 쓰지 않는다.
- 영문 타이틀을 섞을 때는 표지에만 한 번 쓴다.

## 본문 카드 문구 원칙

- 한 장 한 메시지
- 제목 12자 안팎, 본문 2~3줄
- 명사형·단문 위주 (예: "발색, 지속력, 가격 비교")
- 어려운 용어는 풀어 쓴다
- 마지막 장에는 저장·공유·질문 중 행동 한 가지만 (일상형은 짧은 한마디로 마무리해도 됨)

## 캡션 구조

```
[1~2줄] 후킹: 피드에서 "더 보기" 전에 보이는 부분이라 여기서 승부
[본문 3~5줄] 카드 내용의 요약 + 내 경험이나 한마디
[마무리 1줄] 질문 또는 저장·공유 유도
[줄바꿈 후] 해시태그
```

- 캡션이 카드 내용을 그대로 반복하지 않게 한다. 카드는 정보, 캡션은 **내 목소리**.
- 질문은 답하기 쉬워야 댓글이 달린다. ("여러분은 A예요 B예요?" 같은 두 갈래 질문)
- 협찬·광고·제공받은 제품이면 첫 줄이나 눈에 띄는 곳에 표기한다.

## 해시태그 전략

10개 안팎. 너무 많이 붙이지 않는다.

| 구분 | 개수 | 역할 |
|---|---|---|
| 큰 태그 | 약 3 | 검색 풀이 큰 일반 태그 (노출 기회) |
| 중간 태그 | 약 4 | 주제 분야 태그 (관심 있는 사람) |
| 작은·주제 태그 | 약 3 | 이 게시물만의 구체적인 키워드, 내 시리즈 태그 |

- 태그는 **게시물 내용과 실제로 관련 있는 것만** 쓴다.
- 인기 태그는 **검색해서 확인**한다. 기억에 의존하지 않는다.
- 내 계정 고유 태그나 시리즈 태그를 하나 정해서 계속 쓰면 모아 보기 좋다.

## 피해야 할 것

- 효능·효과 단정 ("100% 개선", "치료", "무조건")
- 근거 없는 최상급 ("세계 1위", "가장 좋은")
- 다른 사람의 사진·글을 허락 없이 사용
- 낚시성 표지 (본문이 약속을 못 지킴)
