# insta-planner

키워드 하나로 인스타그램 게시물을 **기획 → 문구 → 디자인 → 캡션 → 업로드 점검**까지 도와주는 Claude Code 스킬입니다.

> "겨울 립 키워드로 인스타 게시물 만들고 싶어"

(어떤 분야든 됩니다. 예: "자취 요리 키워드로 인스타 게시물 만들고 싶어", "요즘 트렌드가 뭐야?")

이렇게 말하면 Claude가 키워드를 조사하고, 주제를 추천하고, 카드뉴스 장수와 구성, 문구, 포인트 색상, 디자인, 캡션, 해시태그까지 이어서 만들어 줍니다.

## 이런 걸 해 줘요

| 단계 | 내용 |
|---|---|
| 1. 키워드 리서치 | 웹 검색으로 트렌드·궁금증·해시태그 조사 (검색 도구가 있을 때) |
| (제품 큐레이션) | "겨울 딥플럼 글로스 틴트 브랜드와 상품을 가져와서 게시물 만들어줘"처럼 말하면 브랜드·제품 정보(가격은 확인일과 함께)를 원문에서 확인해 모으고, 이미지는 **사용 승인을 받은 것만** 넣거나, 사진 자리를 만들어 **직접 사진을 넣을 수 있게** 만듦(HTML 카드는 클릭·끌어다 놓기) |
| 2. 주제 추천 | 후킹 문구, 유형, 카드 장수, 준비 시간과 함께 5개 제안 |
| 3. 기획서 | 목표, 타깃, 핵심 메시지, 카드 구성표 |
| 4. 카드 문구 | 장마다 제목과 본문 작성 |
| 5. 디자인 방향 | 포인트 색상 2~3안(HEX와 **실제 색 견본**으로 미리보기), 폰트, 레이아웃 |
| 6. 디자인 제작 | Canva로 만들기, 없으면 수정 가능한 HTML 카드(PNG 저장) |
| 7. 캡션·해시태그 | 후킹 + 본문 + 마무리 질문, 해시태그 10개 안팎 |
| 8. 업로드 점검 | 광고 표기, 저작권, 효능 표현, 게시 시간 |

뷰티, 일상, 대외활동 후기, 정보, 리뷰 등 **분야에 상관없이** 쓸 수 있습니다. 기본 가이드(references)에 없는 분야도 조사해서 만들어 줍니다.

## 설치

폴더째 아래 위치에 넣으면 됩니다.

- 모든 프로젝트에서 쓰기: `~/.claude/skills/insta-planner/`
- 한 프로젝트에서만 쓰기: `<프로젝트>/.claude/skills/insta-planner/`

터미널에서는 이렇게 복사합니다.

```bash
mkdir -p ~/.claude/skills
cp -R insta-planner ~/.claude/skills/
```

새 세션부터 인식됩니다. `/insta-planner`로 직접 불러도 되고, 아래처럼 말하면 자동으로 불러옵니다.

- "○○ 키워드로 인스타 게시물 만들고 싶어"
- "이번 주 뭐 올리지?"
- "카드뉴스 만들어줘"
- "포인트 색상 추천해줘"

## 처음 쓸 때

`profile.md`가 없어도 바로 시작할 수 있습니다. 게시물을 다 만든 마지막에 Claude가 "`profile.md`를 만들어 둘까요?"라고 묻고, "예"라고 하면 분야·계정 소개, 타깃, 말투·이모지, 목표를 물어서 `profile.md`를 만들어 줍니다. 직접 채우려면 `profile.template.md`를 `profile.md`로 복사해서 수정하세요. 한 번 만들어 두면 다음부터는 묻지 않고 내 계정에 맞게 기획합니다.

## 디자인 결과물 (수정 가능)

- **Canva가 연결돼 있으면** Canva에서 인스타그램 세로 카드(기본 3:4, 4:5가 꼭 필요하면 변환)로 만들어 편집 링크를 줍니다. 문구와 색은 Canva에서 바로 고치면 됩니다. Canva 연결은 Claude 설정의 커넥터(MCP)에서 먼저 해야 합니다.
- **Canva가 없으면** `assets/card-template.html`로 만듭니다. 브라우저에서 열어 글자를 클릭해 고치고, 색과 폰트를 바꾸고, 카드별로 PNG로 저장할 수 있습니다. (인터넷 연결 필요)

## 폴더 구성

```
insta-planner/
├─ SKILL.md              스킬 본체 (흐름과 규칙)
├─ README.md             이 문서
├─ profile.template.md   계정 정보 양식
├─ profile.md            내 계정 정보 (처음 쓰면 자동 생성, 공유할 때는 빼기)
├─ references/
│  ├─ post-types.md      게시물 유형별 카드 장수·구성
│  ├─ color-guide.md     포인트 색상·폰트·레이아웃 가이드
│  ├─ hook-caption.md    후킹·캡션·해시태그 가이드
│  ├─ checklist.md       업로드 전 점검
│  └─ photo-guide.md     제품 사진 구하기·촬영·넣는 법
└─ assets/
   ├─ card-template.html 수정 가능한 HTML 카드 템플릿
   └─ color-swatch.html  색상 조합을 실제 색으로 보여 주는 견본
```

## 내 입맛에 맞게 고치기

- 색 조합을 늘리고 싶으면 `references/color-guide.md`의 표에 한 줄 추가
- 새 게시물 유형은 `references/post-types.md`에 추가
- 내 말투와 시리즈는 `profile.md`에 기록

## 공유할 때

폴더를 그대로 압축하되 **`profile.md`는 빼세요.** 내 계정 정보가 들어 있습니다. 받는 사람은 처음 쓸 때 자기 프로필을 만들게 됩니다.

## 한계

- 인스타그램에 자동으로 올리지 않습니다.
- 팔로워·조회수 분석은 하지 않습니다.
- 최신 트렌드는 웹 검색이 가능한 환경에서만 조사합니다. 검색이 안 되면 일반 지식으로 하고 직접 확인하라고 알려 줍니다.
